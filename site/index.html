Nothing leaves your browser

No server, no account, no analytics. Settings live in your browser's local storage and export to a JSON file when you want a backup.

Hidden, never deleted

The extension hides X's own elements with CSS. Turn a switch off, or pause the whole extension from the header, and X returns to its default interface.

Warnings you opt into

Influence warnings mark posts that read as a sales pitch, FOMO pressure or vague bait. They are off by default and need your own TypeSafe API key. When on, visible post text goes directly to TypeSafe.

Questions

Does it read my posts or messages?

It runs on x.com pages in your browser to hide and restyle elements. It sends nothing anywhere unless you turn on Influence warnings, which send visible public post text to TypeSafe with your own key. Private messages and drafts are never sent.

Does it block every ad?

It hides posts that X labels as promoted, and it has separate switches for Paid partnership and Made with AI labels. X changes its markup often, so a new ad format can appear until the extension is updated.

Does it work in Firefox or Safari?

The source builds a Firefox package and a Safari Xcode project. Only the Chromium build is tested in a real browser on every change, so treat the other two as unverified.

Why does Chrome warn about Developer mode?

Chrome shows that notice for any extension loaded from a folder instead of the Web Store. The code it loads is the ZIP you downloaded, and its SHA-256 checksum is published in release.json.

Where did it come from?

It started as a fork of Minimal Twitter, an MIT-licensed extension, and has since been rebuilt around current X markup with new filters, scrolling limits, a redesigned settings popup and real-browser tests.
